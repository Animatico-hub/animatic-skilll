# AnimaticSkill

Crie séries de animação 3D em primeira pessoa (POV) com o Claude: você diz o tema, a skill sugere a história, cria o
cenário, as vozes, a iluminação, o som e entrega o vídeo vertical pronto para postar, com a escolha final para o
público decidir nos comentários.

## Do que você precisa
- Computador **Windows** ou **Mac**.
- **Claude Code** (app do Claude, aba Code, ou o Claude Code no terminal).
- Conta no **ElevenLabs** (vozes) com créditos, conectada ao Claude.
- O instalador confere e instala o resto: Node.js, FFmpeg e Python.

## Instalação (uma vez só)
1. Nesta página do GitHub, clique no botão verde **Code** e depois em **Download ZIP**. Descompacte em qualquer pasta.
2. Rode o instalador da pasta descompactada:
   - **Windows:** clique com o botão direito em `instalar.ps1` > **Executar com o PowerShell**.
   - **Mac:** abra o **Terminal**, digite `bash ` (com espaço), arraste o arquivo `instalar.sh` para a janela e aperte Enter.
3. Responda **s** quando ele perguntar se pode instalar algum programa que estiver faltando.
4. Feche e abra o Claude Code.

## Como usar
Escreva no Claude Code algo como:
- "quero criar uma série de terror na escola"
- "me dá 3 ideias de série no estilo POV"
- "faz a parte 2 da minha série"

A skill faz uma pergunta, sugere 3 histórias e, depois que você escolher, mostra **prévias em imagem** para você aprovar
antes de gastar créditos. Ela avisa o custo das vozes antes de gerar.

## Atualizar
Quando sair uma versão nova, baixe o ZIP de novo e rode o instalador. Os seus projetos de vídeo ficam em outra pasta
e **não são apagados**.
